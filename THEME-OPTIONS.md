## How to Preview

1. Run `npm run dev`
2. Open the site in your browser
3. Click the paint palette button in the bottom-right corner
4. Select any theme to see it applied instantly
5. Navigate to different pages (Home, Gallery, Pricing, Flavors, Contact) to see the full effect

## Notes
- The theme switcher is for preview only - remove it before going to production
- Each theme overrides all page colors: header, footer, hero sections, cards, buttons, forms, etc.
- Fonts remain the same across all themes (Great Vibes, Playfair Display, Lora)
- Any theme can be further customized once a direction is chosen
